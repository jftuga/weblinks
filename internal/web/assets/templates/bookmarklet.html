Drag this link onto your browser's bookmarks bar:

New Weblink

Clicking it on any page opens a small window with the URL and title already filled in, so you only type the notes and pick a section.

Notes

  • The server address {{.BaseURL}} is baked into the link. If you restart with a different -addr, come back to this page and drag the link again.
  • It opens a window rather than posting directly, so no website you visit can reach this server's API.
  • Saving closes the window automatically.

Source

javascript:(function(){
  window.open(
    '{{.BaseURL}}/add?url=' + encodeURIComponent(location.href) +
      '&title=' + encodeURIComponent(document.title),
    'weblinks_add', 'width=640,height=640');
})();
